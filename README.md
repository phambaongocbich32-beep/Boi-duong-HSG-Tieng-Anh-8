# Ôn thi HSG Tiếng Anh 8

Trang web luyện thi học sinh giỏi Tiếng Anh lớp 8: phát âm Unit 1–3, hình thức từ Unit 1–12, 6 chuyên đề ngữ pháp, viết đoạn văn, đề thi thử có đếm giờ và Sổ lỗi sai.

## Dùng ngay
Mở `index.html` bằng trình duyệt. Không cần cài đặt.

## Đăng lên GitHub Pages
1. Tạo repo mới trên GitHub, tải toàn bộ các file này lên.
2. Vào **Settings → Pages**, chọn **Deploy from a branch**, nhánh `main`, thư mục `/ (root)`, bấm Save.
3. Sau khoảng 1 phút, trang chạy tại `https://<tên-tài-khoản>.github.io/<tên-repo>/`.

## Sửa nội dung
Nội dung nằm trong `src/` (`data1.js`, `data2.js`, `data3.js` là câu hỏi và lý thuyết; `app.js` là logic; `style.css` là giao diện). Sau khi sửa, chạy `python3 build.py` để ghép lại thành `index.html`.
